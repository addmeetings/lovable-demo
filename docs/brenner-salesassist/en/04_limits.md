# 4. Limits of the assistant

**Short version (for the submission, 3 sentences):**

SalesAssist only knows what the salesperson types in. It does not know which quotes are open, when the last follow-up was sent
or what is in the CRM, so it cannot catch mistakes in the input or remind anyone about follow-ups that are due.
Once the team follows up regularly and at volume, it needs more than an assistant: a **CRM integration** that pulls in customer data
and quote status automatically, writes the email back and suggests due follow-ups. On top of that come approval workflows for
discounts and a data protection review for personal customer data, which in live use means Langdock rather than a private
ChatGPT account.

## Expansion stages (outlook)

| Stage | What | When it makes sense |
|---|---|---|
| 1 – Assistant (now) | Prompt in Langdock/ChatGPT, manual input | Immediately, to show value and build acceptance |
| 2 – Assistant with knowledge | Service descriptions, text snippets, signatures and examples of good emails as knowledge files | After 4 weeks, once usage is stable |
| 3 – Integration | CRM/ERP connection (quote data automatically), follow-up reminders, sending from Outlook, logging | With high usage or proven value; requires data protection and IT approval |
